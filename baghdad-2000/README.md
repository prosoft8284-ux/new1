# بغداد ۲۰۰۰ — جاده‌ی زامبی

بازی ماشینی جهان‌باز با تم عراق سال ۲۰۰۰. یک BMW قدیمی زرشکی، شهری خاک‌گرفته و زامبی‌هایی که باید زیرشان بگیری.

## اجرا

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # خروجی در dist/
```

## کنترل

| کلید | کار |
| --- | --- |
| `W` / `↑` | گاز |
| `S` / `↓` | ترمز و دنده‌عقب |
| `A` `D` / `←` `→` | فرمان |
| `Space` | ترمز دستی و دریفت |
| `Shift` | نیترو |
| `G` | تعمیرگاه |
| `M` | قطع/وصل صدا |
| `Esc` | توقف |
| `R` | شروع دوباره (بعد از پایان) |

روی موبایل دکمه‌های لمسی پایین صفحه نمایش داده می‌شوند.

## مکانیک

- **کشتن با سرعت:** هر زامبی یک آستانه‌ی سرعت دارد؛ اگر با سرعت کافی به آن برسی خرد می‌شود. با سرعت کم به ماشین چنگ می‌زند و آسیب می‌زند.
- **سه نوع زامبی:** `walker` معمولی، `runner` سریع (امتیاز دوبرابر) و `brute` بزرگ (آستانه‌ی سرعت بالاتر، امتیاز سه‌برابر، آسیب بیشتر).
- **کمبو:** کشتن‌های پشت‌سرهم در ۳ ثانیه ضریب امتیاز را تا ×۵ بالا می‌برد؛ صفحه‌ی کمبو تایمر دارد.
- **نیترو:** با `Shift` مصرف می‌شود، با گذشت زمان و با هر کشته شارژ می‌شود.
- **دیوانه‌وار (رمپیج):** با رسیدن کمبو به ×۵، هفت ثانیه آستانه‌ی کشتن نصف و امتیاز دوبرابر می‌شود.
- **اسلوموشن:** سه کشته یا بیشتر در یک لحظه، صحنه را کوتاه‌مدت کند می‌کند.

## ارتقاها (تعمیرگاه)

پنج شاخه، هر کدام پنج سطح: موتور، شاسی، سپر کوبنده، میخ‌ها، لاستیک.
تعمیر کامل ماشین ۴۵ امتیاز است. امتیاز، ارتقاها و رکورد در `localStorage` ذخیره می‌شوند.

## صدا

همه‌ی صداها با WebAudio و به‌صورت رویه‌ای ساخته می‌شوند؛ هیچ فایل صوتی در پروژه نیست:

- موتور با دو اسیلاتور که فرکانسشان با سرعت، گاز و نیترو تغییر می‌کند، به‌همراه باد و فیلتر
- موزیک تطبیقی در گام **حجاز** (۱۰۰ BPM) با عود، بیس و دربوکا؛ با بالا رفتن شدت نبرد لایه‌ها اضافه می‌شوند
- افکت‌های برخورد، خرد شدن زامبی، نیترو، ارتقا و پایان بازی

صدا با اولین کلیک روی «سوار شو» شروع می‌شود (محدودیت مرورگرها) و با `M` قطع می‌شود.

## افکت‌ها و انیمیشن

- ذرات استخری (InstancedMesh): گردوخاک چرخ، دود اگزوز، خون، جرقه و دود موتور
- جای لاستیک روی آسفالت هنگام دریفت
- انیمیشن راه رفتن زامبی‌ها (دست و پا و سر)، بیرون آمدن از زمین هنگام اسپاون، و تلوتلو خوردن هنگام مرگ
- تعلیق ماشین: رول در پیچ، شیرجه هنگام ترمز، لرزش جزئی، چرخش چرخ‌ها و فرمان چرخ جلو
- چراغ ترمز، نورافکن، شعله‌ی نیترو
- دوربین تعقیبی با FOV متغیر، لرزش برخورد و خطوط سرعت روی لایه‌ی HUD

## اندروید (APK)

پروژه با Capacitor بسته‌بندی شده است:

```bash
npm run build
npx cap sync android
cd android
JAVA_HOME=$HOME/tools/jdk17 ./gradlew :app:assembleDebug
```

APK در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود (minSdk 22، targetSdk 34، جهت افقی).

## ساختار

- `src/main.js` — حلقه‌ی بازی، ورودی، کمبو/نیترو/رمپیج، دوربین، برخورد
- `src/car.js` — مدل و فیزیک BMW
- `src/zombies.js` — انواع زامبی، هوش تعقیب، کشتن و آسیب
- `src/world.js` — شهر، جاده، ساختمان‌ها، بیلبوردها، نورپردازی
- `src/effects.js` — ذرات و جای لاستیک
- `src/audio.js` — موتور، موزیک و افکت‌ها
- `src/ui.js` — HUD، تعمیرگاه، توقف، پایان بازی
- `src/upgrades.js` — تعریف ارتقاها و ذخیره‌سازی
