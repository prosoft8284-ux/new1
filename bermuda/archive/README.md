# Archive

Old material kept for reference only. The shipping game is `../survival/`.

- `pixi-prototype/` — the first PixiJS/TypeScript attempt at the game. Superseded
  by the vanilla canvas build in `survival/`; it is not built, tested or shipped.
- `bermuda-debug.apk`, `bermuda-survival-v1.1.apk` — debug and first public builds.
- `../bermuda-survival-full.zip` — the original source drop the game grew from.

Current builds live in `../releases/` and the newest APK is always
`bermuda-survival-v<version>.apk`.
