# جزیرهٔ برمودا — نقشهٔ جهان‌باز اشغال‌شده

نقشهٔ یک جزیرهٔ بزرگ گرمسیری در مثلث برمودا که موجودات فضایی آن را اشغال کرده‌اند.
این مخزن فعلاً **نقشهٔ بازی** را می‌سازد: زمین، سواحل، ارتفاعات، رودها، جاده‌ها،
نقاط دیدنی، مناطق اشغال‌شده و پوشش گیاهی — به‌همراه خروجی‌های آماده برای موتور.

اندازهٔ جهان: **۱۲٬۲۸۸ × ۱۲٬۲۸۸ پیکسل** = ۳۸۴ × ۳۸۴ خانه، هر خانه ۳۲ پیکسل.
هر خانه در حدود ۴ متر در نظر گرفته شده؛ یعنی جزیره تقریباً ۱٫۵ کیلومتر در ۱٫۵ کیلومتر
با مقیاس فشرده (سبک فارکرای) است.

## خروجی‌ها

| فایل | توضیح |
| --- | --- |
| `map/bermuda-island.tmx` | نقشهٔ Tiled با سه بخش: `ground` (زمین)، `collision` (عبور/کندی) و `pois` (نقاط دیدنی) |
| `map/tileset.png` | ست کاشی ۳۲ پیکسلی؛ ۲۵ نوع زمین در دو گونه + دو کاشی نشانگر برخورد |
| `map/world.json` | مناطق، نقاط دیدنی (فارسی/انگلیسی)، مسیر جاده‌ها، مناطق فضایی، بهترینی و نقطهٔ شروع |
| `map/props.csv` | ۲۳٬۷۰۰ دارایی پراکنده: درخت، نخل، بوته، سنگ، کریستال، نی و… |
| `map/buildings.json` | ۱۵۴ ساختمان با اندازه، چرخش و سبک سقف |
| `map/_fields.npz` | لایه‌های خام ارتفاع/رطوبت/شیب/کاشی برای ابزارهای بعدی |
| `artifacts/bermuda-island-map.png` | پوستر نقشه (۲۰۴۸×۲۰۴۸) |
| `artifacts/bermuda-detail-*.png` | برش‌های بزرگ‌نمایی‌شده (بندر، جنگل، منطقهٔ فضایی، باند فرودگاه، مناره، جنوب) |

## ساخت دوباره

```bash
python3 tools/generate_world.py   # زمین، POI، جاده، کاشی، TMX، JSON
python3 tools/render_map.py       # پوستر و برش‌های جزئیات
python3 tools/verify_map.py       # اعتبارسنجی خروجی‌ها
```

همه‌چیز از `SEED = 20261114` ساخته می‌شود، پس نتیجه تکرارپذیر است.

## ساختار جزیره

- **بندر کسترل** در خلیج غربی؛ محلهٔ کهنه، اسکله و جادهٔ اصلی جزیره
- **درهٔ آروارهٔ سبز** در شمال با روستا، باند فرودگاه روک، انبار سوخت و دیده‌بانی
- **یال خاکستر** در مرکز: معبد جزر و مد، برج رادیو، غارها، آبشار پرده
- **بیابان‌های جنوبی**: معدن گوگرد، روستای نهر انبه، آبشار دوقلو، رادار یال
- **خلیج شرقی**: شهر خلیج، اسکله، کشتی شکستهٔ کورمورانت
- **جزیرهٔ شمالی** با جادهٔ خاکی و سوزن افتاده؛ دو جزیرهٔ کوچک اطراف

مناطق اشغال‌شده (خاک بنفش، دهانهٔ برخورد و مناره):

| منطقه | موجودات |
| --- | --- |
| `fallen_sky_core` | جنگجوی زره‌پوش، عضبان، جادوگر بیگانه، بالزن، موجود مادر |
| `green_jaw_scar` | خاردار رانده، انگل‌زن، جهش‌یافته، جنگجوی زره‌پوش |
| `south_rift` | جهش‌یافته، جنگجوی زره‌پوش، خاردار رانده |
| `east_landing` | بالزن، عضبان، انگل‌زن، خاردار رانده |

## شخصیت اصلی (فعلاً)

از میان شش بازماندهٔ روی برگهٔ شخصیت‌ها، **متخصص فناوری** انتخاب شده است:
هک ادوات فضایی، خاموش‌کردن سپر مناره‌ها و پهپاد بازیابی — مناسب یک جزیرهٔ اشغال‌شده.
فهرست کامل و قابل‌تعویض در `design/characters.json` است.

## استفاده در موتور (libGDX)

```java
TiledMap map = new TmxMapLoader().load("map/bermuda-island.tmx");
TiledMapTileLayer ground = (TiledMapTileLayer) map.getLayers().get("ground");
TiledMapTileLayer collision = (TiledMapTileLayer) map.getLayers().get("collision");
// gid 51 = عبور ممنوع، gid 52 = عبور کند (آب کم‌عمق، باتلاق، جنگل انبوه)
```

`world.json` را برای نقاط دیدنی، مسیر جاده‌ها، مناطق و بهترینی بخوانید؛
`props.csv` را هنگام بارگذاری منطقه به منطقه جریان دهید (هر سطر: x, y, type, rot, scale).

## محدودیت‌های فعلی

- برچسب‌های روی پوستر انگلیسی‌اند (فونت فارسی با شکل‌دهی حروف در تصویر در دسترس نبود)؛
  نام فارسی همهٔ نقاط در `world.json` هست.
- این مرحله فقط نقشه است؛ حرکت، نبرد و هوش مصنوعی هنوز پیاده نشده.
- هنر شخصیت و موجودات فضایی از برگهٔ طراحی گرفته می‌شود؛ فعلاً هیچ اسپرایت دودویی در مخزن نیست.
