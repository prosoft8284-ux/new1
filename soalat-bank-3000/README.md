# بانک ۳۰۰۰ سوالی جامعه‌شناسی — اپ ۱۷۰ روزه

اپ موبایل (قابل نصب روی اندروید) برای بانک ۳۰۰۰ سوالی کارشناسی ارشد علوم اجتماعی + برنامه مطالعه ۱۷۰ روزه.

هر روز برنامه دقیقاً می‌گوید چه سوال‌هایی، از کدام بخش، با چه روشی و چقدر وقت. کل ۳۰۰۰ سوال دقیقاً یک بار در ۱۰۰ روز مطالعه دور اول می‌آید (هر روز ۳۰ سوال) و آزمون‌ها و مرورها روی همان سوال‌ها سوار می‌شوند.

## تحلیل محتوای بسته

| فایل | درس | تعداد سوال | بخش |
|---|---|---|---|
| `01-nazariye-jameshenasi.txt` | نظریات جامعه‌شناسی | ۷۲۰ | ۲۹ |

بازرسی با ابزارهای خود بسته (`npm run check`): شماره‌گذاری پیوسته، همه سوال‌ها ۴ گزینه، کلید در بازه ۱ تا ۴، تحلیل برای همه، و صفر سوال تکراری.

## کیفیت و ترتیب محتوا

بازرسی کامل ۳۰۰۰ سوال (متن، چهار گزینه، یکتایی گزینه‌ها، کلید، تحلیل):

- هیچ سوالی متن خالی، گزینه خالی، گزینه تکراری، کلید خارج از بازه یا تحلیل خالی ندارد.
- کلیدها متوازن‌اند: هر گزینه دقیقاً ۲۵٪ در هر پنج درس.
- **۱۶۳ تحلیل که کمتر از ۴۰ کاراکتر بودند، درس به درس بازنویسی شدند** (نظریات ۴، جامعه‌شناسی‌ها ۱۷، روش ۳۱، آمار ۳۷، زبان ۷۴). هر تحلیل تازه دو کار می‌کند: می‌گوید چرا پاسخ درست است و گزینه‌های دیگر را رد می‌کند یا نکته‌ی مفهومی را می‌افزاید.
  - الان کوتاه‌ترین تحلیل ۴۰ کاراکتر و میانه‌ی طول تحلیل ۹۲ کاراکتر است.
  - ۷۸۰ تحلیل در بازه‌ی ۴۰ تا ۶۰ کاراکتر مانده‌اند؛ همه‌شان یک جمله‌ی کامل و درست‌اند، ولی به اندازه‌ی بقیه بسط داده نشده‌اند.
  - `tools/patch-exp.js` متن بازنویسی‌شده را از یک نقشه‌ی JSON داخل فایل‌های `soalat/*.txt` می‌نشاند و منبع خام را مرجع نگه می‌دارد.
- **بار هر روز مطالعه دقیقاً ۳۰ سوال است.** جدول اصلی در روزهای ۱۳۰ تا ۱۳۸ نامتوازن بود (یک روز ۱۰۵ سوال و چند روز ۱۰ و ۱۵ سوال)؛ `build-plan.js` این هفت روز را در بلوک‌های ۵ سوالی از درس‌های مختلف بازتوزیع می‌کند تا کسی با روز سه‌ونیم‌برابری روبه‌رو نشود. مجموع و یکتایی سوال‌ها پس از موازنه دوباره بررسی می‌شود.
- **ترتیب جلسه از آسان به سنگین است**: اپ سطح تخمینی هر سوال را از طول صورت سوال، محاسبه‌ای بودن، و تلفیقی/مقایسه‌ای بودن می‌سنجد (۱ تا ۳) و در هر بلوک، سبک‌ترها را اول می‌گذارد. ترتیب درس‌ها و بلوک‌های روز تغییر نمی‌کند؛ فقط داخل هر رشته.

## ساختار پروژه

```
soalat-bank-3000/
├── soalat/                 # متن خام ۵ فایل سوال (منبع اصلی، دست‌نخورده)
├── barnameh/               # برنامه ۱۷۰ روزه (Markdown، منبع حقیقت برنامه)
├── tools/
│   ├── build-data.js       # txt → data/*.json + ساخت app/plan.html
│   ├── build-plan.js       # جدول ۱۷۰ روزه → data/plan.json + اعتبارسنجی پوشش
│   ├── check.js            # اعتبارسنجی ساختار سوال‌ها
│   ├── dups.js             # یافتن سوال تکراری
│   ├── plan.js             # تولید برنامه از بانک
│   ├── rekey.js            # جابه‌جایی متعادل جایگاه کلید (فایل خام را تغییر می‌دهد)
│   └── shuffle.js          # درهم‌ریزی گزینه‌ها با seed (فایل خام را تغییر می‌دهد)
├── data/                   # خروجی تولیدشده: index.json، plan.json، پنج فایل درس
├── app/                    # اپ موبایل: index.html، app.js، styles.css، manifest، service worker، آیکون‌ها
└── server.js               # سرور استاتیک بدون وابستگی
```

## اجرا

```bash
npm run build   # ساخت data/*.json و data/plan.json و app/plan.html
npm start       # http://localhost:3000
npm run check   # اعتبارسنجی بانک سوال
```

## اپ چه می‌کند

چهار تب:

- **امروز** — روز جاری برنامه بر پایه تاریخ شروعی که انتخاب می‌کنی: تعداد سوال، فهرست بلوک‌ها (درس + بخش + بازه سوال)، روتین همان روز هفته، و روش خواندن. هر بلوک را جدا یا همه روز را یک‌جا می‌زنی.
- **برنامه** — هر ۱۷۰ روز، گروه‌بندی‌شده در ۵ فاز؛ هر روز قابل باز کردن است، حتی اگر امروز نباشد.
- **مرور** — سوال‌های نادرست ثبت‌شده، با پاسخ درست؛ یک دکمه برای مرور ۲۰ سوالی.
- **پیشرفت** — درصد کل، دقت، و نوار پیشرفت هر درس.

حالت‌های آزمون:

- **مطالعه** — گزینه‌ها را می‌زنی و بازخورد + تحلیل همان لحظه می‌آید؛ یا با «نمایش پاسخ» اول پاسخ را می‌بینی و بعد «می‌دانستم / نمی‌دانستم» را می‌زنی.
- **آزمون مبحثی هفتگی** — ۲۵ سوال (۱۵ از همان هفته + ۱۰ از هفته قبل)، ۲۵ دقیقه، بدون بازخورد بین سوال‌ها، کارنامه در پایان.
- **آزمون جامع / شبیه‌ساز** — ۲۰۰ سوال تصادفی از کل بانک با زمان‌سنج.

پیشرفت در `localStorage` ذخیره می‌شود؛ سوال‌ها با service worker آفلاین هم بارگذاری می‌شوند.

## نصب روی اندروید

سرور را در دسترس دستگاه بگذار و آدرس را در کروم باز کن، سپس منوی سه‌نقطه ← **افزودن به صفحه اصلی**. اپ در حالت standalone (بدون نوار آدرس) باز می‌شود و آفلاین کار می‌کند.

## فایل APK اندروید

`apk/soalat-3000-170ruz.apk` — اپ کامل و آفلاین (۴.۵ مگابایت)، بسته‌بندی‌شده با Capacitor ۸.

| مشخصه | مقدار |
|---|---|
| نام بسته | `ir.soalat.bank3000` |
| نام نمایشی | ۳۰۰۰ سوال |
| اندروید | ۷.۰ به بالا (minSdk 24) |
| هدف | Android 16 / API 36 |
| امضا | debug keystore (برای استفاده شخصی؛ انتشار در Play به keystore انتشار نیاز دارد) |

نصب: فایل را روی گوشی کپی کن، «نصب از منابع نامشخص» را برای فایل‌منیجر یا مرورگر اجازه بده و APK را باز کن.

بازسازی پس از تغییر کد:

```bash
cd mobile
JAVA_HOME=$HOME/tools/jdk21 ANDROID_HOME=$HOME/android-sdk ./build-apk.sh
```

پروژه‌ی بومی در `mobile/android/` است (Capacitor 8، Gradle 8.14.3، compileSdk 36). فایل‌های اپ و داده قبل از هر بیلد از `app/` و `data/` داخل `mobile/www/` کپی می‌شوند؛ منبع حقیقت همان دو پوشه است.

## نکته‌ها

- `tools/rekey.js` و `tools/shuffle.js` فایل‌های متنی اصلی را درجا تغییر می‌دهند؛ پیش از اجرا از `soalat/` پشتیبان بگیر.
- «روز ۱» همان تاریخی است که در تنظیمات اپ انتخاب می‌کنی؛ تاریخ در داده ذخیره نشده است.
- `app/plan.html` نسخه چاپی/خواندنی برنامه است و از همان Markdown ساخته می‌شود.
