# بانک ۴۰۰۰ سوالی جامعه‌شناسی — اپ ۱۷۰ روزه

اپ موبایل (قابل نصب روی اندروید) برای بانک ۴۰۰۰ سوالی کارشناسی ارشد علوم اجتماعی + برنامه مطالعه ۱۷۰ روزه.

هر روز برنامه دقیقاً می‌گوید چه سوال‌هایی، از کدام بخش، با چه ترتیبی و چقدر وقت. کل ۴۰۰۰ سوال دقیقاً یک بار در ۱۰۰ روز مطالعه دور اول می‌آید (هر روز ۴۰ سوال = ۸ بلوک ۵ سوالی) و آزمون‌ها و مرورها روی همان سوال‌ها سوار می‌شوند.

## کیفیت و ترتیب محتوا

بازرسی کامل ۴۰۰۰ سوال (متن، چهار گزینه، یکتایی گزینه‌ها، کلید، تحلیل):

- هیچ سوالی متن خالی، گزینهٔ خالی، گزینهٔ تکراری، کلید خارج از بازه یا تحلیل خالی ندارد.
- کوتاه‌ترین تحلیل ۴۰ کاراکتر و میانهٔ طول تحلیل ۱۰۶ کاراکتر است؛ هر تحلیل می‌گوید چرا پاسخ درست است و گزینه‌های دیگر را رد می‌کند یا نکتهٔ مفهومی می‌افزاید. ۵۵۰ تحلیل همچنان کوتاه (زیر ۵۵ کاراکتر) است؛ درست اما فشرده.
- **ترتیب بخش‌ها بر اساس سرفصل است، نه ترتیب تألیف.** `tools/reorder.js` هر بلوک بخش (سرتیتر + سوال‌هایش، به‌همراه متن درک مطلب) را یک واحد جابه‌جایی می‌گیرد و بر اساس نقشهٔ موضوعی هر درس می‌چیند: نظریه از مبانی و کلاسیک‌ها (مارکس، دورکیم، وبر) به کنش متقابل، کارکردگرایی، بازخوانی کلاسیک‌ها، انتقادی، فمینیسم، معاصر، ایران و تلفیقی؛ جامعه‌شناسی‌های مختلف از خانواده و آموزش و دین به کار و اقتصاد، شهر، قومیت، سیاست، انحراف، رسانه، سلامت، جمعیت، محیط زیست و فناوری؛ روش از مبانی به سنجش، نمونه‌گیری، طرح، علّی، کیفی، اسناد، اخلاق و ارزیابی؛ آمار از توصیف و پراکندگی به احتمال، برآورد، استنباط، ناپارامتری و رگرسیون؛ زبان از واژگان به دستور، درک مطلب، کلوز و ترجمه. شمارهٔ بخش‌ها از ۱ و شمارهٔ سوال‌ها به‌صورت پیوسته دوباره نوشته می‌شوند و شمارهٔ ارجاع در متن‌های درک مطلب هم به‌روز می‌شود؛ بنابراین «بخش نوزدهم» تکراری وجود ندارد.
- **ترتیب سوال‌ها در برنامه تثبیت‌شده است.** `tools/gen-plan-md.js` جدول ۱۷۰ روزه را بازتولید می‌کند: هر روز ۴۰ سوال، به ترتیب ثابت درس‌ها (نظریات ← جامعه‌شناسی‌ها ← روش ← آمار ← زبان) و درون هر درس از بخش نخست به بخش‌های پیشرفته. پس روزهای اول پایه‌اند و روزهای آخر به تلفیقی/محاسباتی می‌رسند؛ هیچ سوالی جا نمی‌افتد و هیچ سوالی دو بار نمی‌آید (پوشش ۱۰۰٪ در `build-plan.js` بررسی می‌شود).
- **ترتیب جلسه از آسان به سنگین است**: اپ سطح تخمینی هر سوال را از طول صورت سوال، محاسبه‌ای بودن، و تلفیقی/مقایسه‌ای بودن می‌سنجد (۱ تا ۳) و درون هر درس، سبک‌ترها را اول می‌گذارد. ترتیب درس‌ها و بلوک‌های روز تغییر نمی‌کند.
- **پوشش سرفصل‌های کم‌سوال تکمیل شد.** `tools/audit-quality.js --coverage` بانک را با نقشهٔ سرفصل کنکور ارشد علوم اجتماعی (نظریه‌ها، حوزه‌های جامعه‌شناسی، روش، آمار، زبان) تطبیق می‌دهد و موضوع‌های کم‌پوشش را نشان می‌دهد. بر پایهٔ آن، `tools/curate.js` ۲۱ سوال تکراری/هم‌موضوع را با ۲۱ سوال تازه جاگذاری کرد: مانهایم و نظریهٔ مبادله (هومز، بلاو) در نظریات؛ جامعه‌شناسی جنگ و صلح در جامعه‌شناسی‌ها؛ تحلیل مسیر، مشاهدهٔ مشارکتی، اعتبار پاسخگو و تحلیل روایت در روش؛ دامنهٔ بین‌چارکی، t تک‌نمونه‌ای، کولموگروف–اسمیرنوف، آزمون نسبت و همبستگی چندگانه در آمار؛ وارونگی، وجه التزامی، بند موصولی کوتاه‌شده، هم‌آیند، حرف تعریف، عبارت وصفی، کمیت‌سنج غیرشمارشی، gerund و مجهول گزارشی در زبان. تعداد هر فایل ثابت ماند تا برنامهٔ ۱۷۰ روزه (۱۰۰ روز × ۴۰ سوال) دست‌نخورده بماند.
- **تحلیل‌های ناکافی بازنویسی شدند.** `tools/enrich-explanations.js` ۳۳ تحلیل کوتاه را که فقط نتیجه را تکرار می‌کردند با تحلیل کامل (چرا این گزینه درست است، چرا گزینه‌های دیگر نه، نکتهٔ مفهومی) جایگزین کرد؛ بقیهٔ ۴۰۰۰ تحلیل با `tools/audit-quality.js` از نظر تناقض با کلید، کلیشه‌ای بودن و تکرار بررسی می‌شوند.

## اجرا

```bash
npm run build   # ساخت data/*.json و data/plan.json و app/plan.html
npm start       # http://localhost:3000
node tools/reorder.js --dry  # نمایش ترتیب پیشنهادی بخش‌ها بدون تغییر فایل
node tools/reorder.js        # مرتب‌سازی بخش‌ها و شماره‌گذاری مجدد
node tools/audit-quality.js            # بازرسی تحلیل، کلید، تلهٔ طول گزینه و تکرار
node tools/audit-quality.js --coverage # افزون بر آن، پوشش هر موضوع سرفصل
node tools/curate.js --dry             # نمایش جاگذاری سوال‌های تازه بدون تغییر فایل
npm run check   # اعتبارسنجی بانک سوال
npm test        # تست پخش عقب‌افتادگی، صف دورهٔ بدون تکرار و ثبت اعلان
python3 tools/make-icons.py   # ساخت دوبارهٔ لوگو و آیکون‌ها
```

## اپ چه می‌کند

پنج تب:

- **امروز** — روز جاری برنامه بر پایه تاریخ شروعی که انتخاب می‌کنی: تعداد سوال، فهرست بلوک‌ها (درس + بخش + بازه سوال)، روتین همان روز هفته، و روش خواندن. هر بلوک را جدا یا همه روز را یک‌جا می‌زنی.
- **برنامه** — هر ۱۷۰ روز، گروه‌بندی‌شده در ۵ فاز؛ هر روز قابل باز کردن است، حتی اگر امروز نباشد.
- **مرور** — سه ابزار: سوال‌های نادرست ثبت‌شده با پاسخ درست، **دورهٔ سوالات قبلی** (فقط سوال‌هایی که زده‌ای، تصادفی و بدون تکرار تا پایان یک دور، با نوار پیشرفت و شمارش باقی‌مانده) و **تمرین آزاد** (۱۰/۲۵/۵۰ سوال تصادفی از کل بانک برای وقتی سهمیهٔ روز تمام شده).
- **پیشرفت** — درصد کل، دقت، و نوار پیشرفت هر درس.
- **راهنما** — توضیح کامل برنامه: منطق ترتیب سوال‌ها، یک روز مطالعه قدم‌به‌قدم، حالت‌های آزمون، مرور، دقیقاً چه چیزی و کجا ذخیره می‌شود، آفلاین و نصب.

حالت‌های آزمون:

- **مطالعه** — گزینه‌ها را می‌زنی و بازخورد + تحلیل همان لحظه می‌آید؛ یا با «نمایش پاسخ» اول پاسخ را می‌بینی و بعد «می‌دانستم / نمی‌دانستم» را می‌زنی.
- **آزمون مبحثی هفتگی** — ۲۵ سوال (۱۵ از همان هفته + ۱۰ از هفته قبل)، ۲۵ دقیقه، بدون بازخورد بین سوال‌ها، کارنامه در پایان.
- **آزمون جامع / شبیه‌ساز** — ۲۰۰ سوال تصادفی از کل بانک با زمان‌سنج.

ذخیره‌سازی در `localStorage` با کلید ثابت `sb:v3`: تاریخ شروع، پاسخ هر سوال (درست/نادرست، تعداد تلاش، زمان)، روزهای تمام‌شده، محل ادامهٔ هر بلوک، صف دورهٔ سوالات قبلی و تنظیم یادآوری. سوال‌ها با service worker آفلاین هم بارگذاری می‌شوند.

### جبران روزهای عقب‌افتاده

اگر یک یا چند روز را انجام ندهی، سوال‌های پاسخ‌ندادهٔ آن روزها جمع می‌شوند و بین روزهای مطالعهٔ باقی‌مانده پخش می‌شوند (به‌طور مساوی، بدون سقف مصنوعی). بالای صفحهٔ «امروز» تعداد کل و سهم هر روز نمایش داده می‌شود و در کارت هر روز یک بلوک «جبران» با دکمهٔ شروع می‌آید؛ پس نه بار یک روز سنگین می‌شود و نه سوالی جا می‌ماند.

### یادآوری روزانه

در تنظیمات، ساعت دلخواه را انتخاب و یادآوری را روشن کن. اپ از `@capacitor/local-notifications` استفاده می‌کند و هر روز همان ساعت یک اعلان می‌فرستد (اندروید ۱۳+ اجازهٔ اعلان می‌خواهد؛ اگر اجازهٔ «اعلان دقیق» نباشد، زمان‌بندی معمولی ثبت می‌شود). پلاگین با esbuild داخل `app/vendor-notifications.js` باندل شده و در وب‌ویو قبل از `app.js` بارگذاری می‌شود؛ اگر باندل نبود، دکمه با پیام روشن می‌کند که پلاگین در دسترس نیست. پس از روشن‌کردن، با `getPending()` بررسی می‌شود که زمان‌بندی واقعاً در سیستم اعلان‌های گوشی نشسته باشد و در تنظیمات «✓ ثبت شد» نشان داده می‌شود. در نسخهٔ وب این دکمه غیرفعال است و پیام می‌دهد که اعلان فقط در APK کار می‌کند.

## ارتباط با کنکور ارشد جامعه‌شناسی

`node tools/exam-audit.js` بانک را با پنج درس دفترچهٔ مجموعهٔ علوم اجتماعی تطبیق می‌دهد (زبان عمومی و تخصصی، آمار، روش تحقیق، نظریه‌های جامعه‌شناسی، جامعه‌شناسی) و بر پایهٔ عنوان بخش‌ها سه سطح می‌سازد:

| سطح | تعداد | سهم |
|---|---|---|
| هستهٔ پرتکرار (سطح معمول آزمون) | ۲۷۰۷ | ۶۷.۷٪ |
| تعمیقی/کم‌تکرار ولی درون سرفصل | ۱۱۹۸ | ۲۹.۹٪ |
| فراتر از سطح معمول (دیجیتال، هوش مصنوعی، ارزیابی برنامه) | ۹۵ | ۲.۴٪ |

یعنی ۱۰۰٪ سوال‌ها در پنج درس رسمی آزمون‌اند و حدود ۹۷.۶٪ در سطحی هستند که برای آزمون ارشد به کار می‌آید. این تقسیم بر پایهٔ برچسب بخش‌هاست، نه داوری تک‌تک سوال‌ها.

## لوگو و آیکون

لوگوی تازه با `tools/make-icons.py` ساخته می‌شود: کتاب باز کرم‌رنگ و ستارهٔ زعفرانی روی پس‌زمینهٔ سرمه‌ای. خروجی‌ها: `app/icon-192.png`، `app/icon-512.png`، `app/icon-1024.png` و همهٔ `mipmap-*`های لانچر اندروید (شامل آیکون تطبیقی و گرد).

## نصب روی اندروید

**APK:** `apk/soalat-4000-170ruz.apk` — اپ کامل و آفلاین، بسته‌بندی‌شده با Capacitor ۸.

| مشخصه | مقدار |
|---|---|
| نام بسته | `ir.soalat.bank3000` |
| نام نمایشی | ۴۰۰۰ سوال |
| اندروید | ۷.۰ به بالا (minSdk 24) |
| هدف | Android 16 / API 36 |
| امضا | debug keystore (برای استفاده شخصی؛ انتشار در Play به keystore انتشار نیاز دارد) |

نصب: فایل را روی گوشی کپی کن، «نصب از منابع نامشخص» را برای فایل‌منیجر یا مرورگر اجازه بده و APK را باز کن.

**نسخه وب:** سرور را در دسترس دستگاه بگذار و آدرس را در کروم باز کن، سپس منوی سه‌نقطه ← **افزودن به صفحه اصلی**.

بازسازی پس از تغییر کد:

```bash
cd mobile
JAVA_HOME=$HOME/tools/jdk21 ANDROID_HOME=$HOME/android-sdk ./build-apk.sh
```

پروژه‌ی بومی در `mobile/android/` است (Capacitor 8، Gradle 8.14.3، compileSdk 36). فایل‌های اپ و داده قبل از هر بیلد از `app/` و `data/` داخل `mobile/www/` کپی می‌شوند؛ منبع حقیقت همان دو پوشه است.

## نکته‌ها

- `tools/rekey.js` و `tools/shuffle.js` فایل‌های متنی اصلی را درجا تغییر می‌دهند؛ پیش از اجرا از `soalat/` پشتیبان بگیر.
- «روز ۱» همان تاریخی است که در تنظیمات اپ انتخاب می‌کنی؛ تاریخ در داده ذخیره نشده است.
- `app/plan.html` نسخه چاپی/خواندنی برنامه است و از همان Markdown ساخته می‌شود.
- اگر محتوای سوال‌ها را عوض کردی، ترتیب: `npm run build` → `npm run check` (و در صورت تغییر تعداد، `node tools/gen-plan-md.js` پیش از `build-plan.js`).
