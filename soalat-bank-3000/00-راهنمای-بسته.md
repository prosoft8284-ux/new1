# بستهٔ بانک ۴۰۰۰ سؤالی ارشد جامعه‌شناسی

این بسته شامل همهٔ سؤال‌ها، دادهٔ ساخته‌شده، ابزارهای بازنویسی و سند سبک آزمون است.

## محتوا

| مسیر | چیست |
|---|---|
| `soalat/01..05*.txt` | منبع اصلی: ۴۰۰۰ سؤال (۹۶۰ + ۱۰۲۰ + ۶۹۵ + ۶۸۵ + ۶۴۰) |
| `data/*.json` | همان سؤال‌ها به شکل دادهٔ آمادهٔ اپ (آخرین ساخت) |
| `tools/` | ابزار بازنویسی، اعتبارسنجی، ممیزی و پروفایل سبک |
| `tools/rewrites/` | همهٔ دسته‌های بازنویسی‌شده + `PROGRESS.md` (روش و وضعیت) |
| `tmp/exam/` | دو دفترچهٔ واقعی آزمون (PDF) + متن استخراج‌شده + `style-profile.md` |
| `app/`, `barnameh/`, `server.js`, `tests/` | اپ وب، برنامهٔ مطالعه و تست‌ها |

## قالب هر سؤال در `soalat/*.txt`

```
۱) متن صورت سؤال
   ۱. گزینه یک
   ۲. گزینه دو
   ۳. گزینه سه
   ۴. گزینه چهار
✔ کلید: گزینه ۲
✎ تحلیل: توضیح پاسخ درست و رد سه گزینهٔ دیگر
```

شمارهٔ سؤال، شمارهٔ گزینه و شمارهٔ کلید را جابه‌جا نکنید؛ ابزارها بر همین قالب تکیه دارند.

## وضعیت فعلی

- ۴۰۰۰ سؤال، هر چهار گزینه + کلید + تحلیل.
- ۸۵۰ سؤال بازنویسی/بازچینش‌شده (سؤال ۱ تا ۱۹۴ فایل نظریه با سبک آزمون، بقیه با بازنویسی کامل یا دنباله).
- تلهٔ «کلید = بلندترین گزینه»: از ۲۹۳۶ به ۲۳۱۶ کاهش یافته.

## بررسی و ساخت

```bash
node tools/check.js          # ساختار: باید ALL OK بدهد
node tools/dups.js           # سؤال تکراری: باید ۰ بدهد
npm test                     # ۱۱ تست
node tools/audit-quality.js  # ممیزی کیفیت و شمارش تله‌ها
npm run build                # بازسازی data/*.json از soalat/*.txt
```

## ابزارهای بازنویسی

```bash
node tools/dump-restyle.js 1 195 60        # نمایش سؤال‌های ۱۹۵ به بعد فایل ۱
node tools/apply-restyle.js tools/rewrites/restyle/rsN.json   # فشرده‌کردن کلید
node tools/apply-rewrites.js tools/rewrites/batchN.json       # بازنویسی کامل گزینه‌ها
node tools/apply-tails.js tools/rewrites/tails/batchTN.json   # بازنویسی دنبالهٔ گزینه‌ها
```

هر سه ابزار قبل از نوشتن، ساختار فایل را اعتبارسنجی می‌کنند و در صورت خرابی چیزی نمی‌نویسند.
